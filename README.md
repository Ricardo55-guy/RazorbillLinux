# About 
Meet Razorbill Linux. an Alpine-based Linux distribution meant to be ready for anything, and lightweight, just like the name inspiration, Razorbill Linux. The main spotlight of features are a TUI installer, musl libc, busybox, and limine. Cybersecurity? Gaming? Hardened and optimized custom kernel. Speed? Choose a lightweight XFCE in the installer. Stability or web browsing and not much? Choose Cinnamon in the installer. Ricing? KDE Plasma. You get to pick, and every case is tailored for immediately. Extra packages or internet connection in the installer? Got that down. All just like a razorbill who can waddle, fly, and swim. Small and built for anything.
